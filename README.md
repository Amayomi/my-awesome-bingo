## 🌟 What is Soc Ops?

Soc Ops (Social Operations) is a modern, interactive bingo game designed to energize in-person gatherings, team-building events, and networking mixers. Say goodbye to forced small talk and hello to natural, fun conversations!

### Why Soc Ops?

- 🎯 **Instant Engagement** - Gets everyone talking from the moment they arrive
- 💬 **Natural Conversations** - Questions spark genuine, interesting discussions
- 🏆 **Friendly Competition** - The race to get 5-in-a-row adds excitement
- 📱 **Mobile-First** - Works seamlessly on phones, tablets, and desktops
- ⚡ **Zero Setup** - Just share the link and play!

---

## ✨ Features

🎨 **Beautiful Interface** - Clean, modern design built with React 19 and Tailwind CSS v4  
🔄 **Randomized Boards** - Every game is unique with shuffled questions  
🎊 **Celebration Animations** - Confetti and effects when someone wins  
📲 **PWA Ready** - Install as an app on any device  
🚀 **Lightning Fast** - Built with Vite for instant load times  
♿ **Accessible** - Keyboard navigation and screen reader friendly

## 🎮 How to Play

<div align="center">

```
1️⃣ Find someone who matches a question
       ⬇️
2️⃣ Tap the square to mark it
       ⬇️
3️⃣ Get 5 in a row (horizontal, vertical, or diagonal)
       ⬇️
4️⃣ BINGO! 🎉
```

</div>

**Example Questions:**
- 🚴 bikes to work
- 🌍 has lived in another country
- 🎸 plays an instrument
- 🗣️ speaks more than 2 languages
- 🏃 has run a marathon

## 🚀 Quick Start

### Prerequisites

- [Node.js 22](https://nodejs.org/) or higher

### Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) and start playing! 🎉

### Production Build

```bash
npm run build
```

The app automatically deploys to GitHub Pages when you push to `main`.
